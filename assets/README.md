# Asset sources

- GSAP 3.14.2, ScrollTrigger and Flip: locally vendored distribution from the GSAP npm package via jsDelivr. Official documentation and licensing: https://gsap.com/docs/v3/ and https://gsap.com/community/standard-license/.
- Outfit and Plus Jakarta Sans: self-hosted font files sourced from Google Fonts. Both use the SIL Open Font License. Upstream: https://github.com/google/fonts/tree/main/ofl/outfit and https://github.com/google/fonts/tree/main/ofl/plusjakartasans.
- Icons: Phosphor Icons core 2.1.1 regular SVG assets, MIT licensed. Upstream: https://github.com/phosphor-icons/core.
- Product and botanical photographs under `images/` predate this redesign. Do not infer ownership, authenticity or licensing from their presence; confirm these before public launch.
